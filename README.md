# Support

This app stores decks and review history on the device. There is no account to reset and no server copy of your cards.

## Moving to a new phone

Use iCloud Backup on iPhone, or Android backup, then restore that backup on the new device. This app does not sync live between devices.

## Importing cards

You can import a CSV file from the deck screen. The file stays on the device.

---

# サポート

このアプリは、デッキと復習の記録を端末の中に保存します。アカウントのリセットも、サーバー上のカードのコピーもありません。

## 機種変更

iPhone なら iCloud バックアップ、Android なら Android のバックアップを使い、新しい端末でそのバックアップから復元してください。このアプリは端末の間で同期しません。

## カードの読み込み

カードはデッキ画面から CSV で取り込めます。ファイルは端末の中に残ります。
